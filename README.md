# TO-DOes

<p>Browser-based to-do list with current user date, task/description, priority, due date, and completion functions!</p>

<p> It is meant to be used as a way to keep track on tasks that have to be done, without the hassle of maintaining a journal!</p>


<p> Test it out at https://gs-material.github.io/TO-DO-es/ ! </p>
